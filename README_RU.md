# Majestic RP Linux Fix

Графическая русско-английская утилита для запуска Majestic RP с GTA V Legacy через Steam/Proton.

Проект содержит только собственный код этой утилиты. Сторонний раннер не включён; его отдельная загрузка выполняется только после явного согласия пользователя.

Графический мастер может по явному согласию пользователя автоматически скачать отдельно лицензированный MIT-раннер из закреплённого коммита. Архив проверяется по SHA-256, а оригинальная лицензия сохраняется в каталоге зависимости.

## Графическая установка

```bash
python3 install_app.py
```

Команда устанавливает программу в `~/.local/share/majestic-rp-linux-fix`, добавляет её в меню KDE и создаёт ярлык на рабочем столе. После этого откройте **Majestic RP Linux Fix** и нажмите **Установить или исправить**.

## Возможности

- создаёт отдельную копию Proton Experimental, не изменяя оригинал;
- применяет исправление Wine 11 для ошибки `ERR_FAILED_TO_INJECT` / `0xc0000409`;
- назначает исправленный Proton для Steam AppID `271590`;
- настраивает Majestic, Rockstar Launcher и GTA в одном Proton-префиксе;
- запускает Majestic, показывает состояние и журнал инъекции;
- делает резервные копии конфигурации и позволяет отключить фикс без удаления файлов.

## Использование

Откройте ярлык **Majestic RP Linux Fix** и выберите действие. Для первой установки закройте игру; утилита предложит штатно закрыть Steam.

Нужна именно **Grand Theft Auto V Legacy**, не Enhanced. Proton Experimental должен быть установлен в Steam.

Также используется отдельно установленный внешний раннер `majestic-rp-linux`. Графический мастер может скачать его автоматически после показа источника и лицензии. По умолчанию утилита ищет его в `~/.local/share/majestic-rp-runner` и каталогах `~/.local/share/majestic-rp-runner-*`.

## Важно

Это неофициальная пользовательская утилита. Исправление основано на публичном исследовании:
https://github.com/digitalhorizongroup/majestic-rp-linux/issues/18

См. `THIRD_PARTY.md`: сторонние исходники и бинарники в этот проект не включены.

Исправленная копия находится в `Steam/compatibilitytools.d/Proton-Exp-MJLX`. Оригинальный Proton Experimental не модифицируется.
